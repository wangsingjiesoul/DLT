# PushPlus 微信与 QQ 双通道通知设计

## 目标

同一期预测同时发送到微信和 QQ。任一渠道暂时失败时，后续重试只发送失败渠道，避免已经成功的渠道重复收到消息。

## 方案

- 使用 `PUSHPLUS_CHANNELS=wechat,qq` 声明多个渠道，保留 `PUSHPLUS_CHANNEL` 单渠道兼容配置。
- 每个通知适配器提供稳定的 `notification_id`，例如 `pushplus:wechat`、`pushplus:qq`。
- 自动化状态按目标期号保存已成功渠道列表，而不是只保存一个全局期号。
- 每个渠道成功后立即原子写入状态；后续渠道异常时让异常继续上抛，由调度器按原有间隔重试。
- 旧版 `last_notified_issue` 状态迁移时，将第一配置渠道视为已发送，避免升级后重复发送微信。

## 验证

- 同一期同一渠道不会发送两次。
- 微信成功、QQ 首次失败后，第二次运行只重试 QQ。
- 重复配置的渠道会去重。
- `.env` 继续由 Git 忽略，Token 不进入仓库。
