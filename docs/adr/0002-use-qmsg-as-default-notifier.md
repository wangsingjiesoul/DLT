# ADR-0002：默认使用 Qmsg酱发送 QQ 通知

## 状态

已接受，取代 ADR-0001

## 背景

项目需要在个人部署后长期自动发送下一期大乐透候选号码。PushPlus 的发送接口要求实名认证，而实名认证需要付费，不符合用户的零成本要求。WxPusher 虽然免费，但其微信 ClawBot 通道存在激活有效期，不适合每周无人值守运行。

## 决策

默认使用 Qmsg酱发送 QQ 单聊消息，也允许通过 `QMSG_GROUP` 发送到已绑定的 QQ 群。通知凭证只从 `QMSG_KEY` 环境变量读取。现有 PushPlus 适配器继续作为可选兼容渠道，通过 `NOTIFY_PROVIDER=pushplus` 启用。

## 结果

### 正面

- 无需购买会员或付费实名认证。
- QQ 登录、添加机器人好友并发送 Key 后即可接收单聊消息。
- 每周三次的开奖频率远低于接口的日调用额度。
- 不依赖非官方 QQ 客户端协议，部署端只调用 HTTPS API。

### 负面

- 仍依赖第三方通知服务的可用性与内容审核规则。
- API Key 位于请求路径中，错误日志必须避免输出完整 URL。
- 接口成功表示服务端接受任务，最终 QQ 投递仍由第三方异步完成。

## 备选方案

- WxPusher：免费，但微信 ClawBot 需要定期重新激活；独立 App 接收则不属于微信或 QQ。
- 企业微信群机器人：官方且免费，但需要使用企业微信客户端和群聊。
- 自建 OneBot/NapCat：控制力强，但需要维护登录态，并存在个人 QQ 账号风控风险。
