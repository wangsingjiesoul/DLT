# 大乐透历史开奖号码

本项目保存中国体育彩票超级大乐透历史开奖号码，仅包含大乐透，不包含双色球、福彩 3D、七乐彩、排列三或排列五等其他彩种。

## 数据文件

- `data/dlt.json`：大乐透全部历史开奖数据，按开奖日期从新到旧排列。
- 当前导入范围：`07001`（2007-05-30）至 `26121`（2026-10-24），共 2,939 期。

每条记录格式如下：

```json
{
  "issue": "26121",
  "date": "2026-10-24",
  "front": ["06", "08", "19", "24", "25"],
  "back": ["01", "08"]
}
```

- `issue`：期号
- `date`：开奖日期
- `front`：5 个前区号码，范围 01–35
- `back`：2 个后区号码，范围 01–12

## 数据来源

数据于 2026-10-25 从 [Justdoitfor/my-lottery-data](https://github.com/Justdoitfor/my-lottery-data) 的 `data/dlt.json` 导入。上游仓库说明其原始数据来自 500彩票网历史数据表格。

彩票数据仅供学习与数据分析使用，请以中国体育彩票官方公布的开奖结果为准。
